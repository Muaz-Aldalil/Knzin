# Internationalization (i18n) — Translations, Locales & RTL

Load on any app serving users in more than one language.

---

## Library per Stack

| Stack | Library |
|---|---|
| Next.js (app router) | `next-intl` |
| Next.js (pages router) | `next-i18next` |
| React (Vite) | `react-i18next` or `Lingui` |
| Vue / Nuxt | `vue-i18n` / `@nuxtjs/i18n` |
| Angular | `@angular/localize` |
| Svelte | `svelte-i18n` or `Lingui` |
| Astro | `astro-i18next` |

## Translation File Structure

```
/locales/
  en/
    common.json       — nav, footer, buttons
    dashboard.json    — dashboard-specific keys
    checkout.json     — checkout flow
  ar/
    common.json
    dashboard.json
    checkout.json
```

**Key naming:** dot-notation, flat keys, namespaced by feature.
```json
{
  "nav.home": "Home",
  "nav.settings": "Settings",
  "dashboard.title": "Your Dashboard",
  "checkout.total": "Total: {amount}"
}
```

## ICU Message Syntax

```json
{
  "items_count": "{count} items",
  "items_plural": "{count, plural, one {# item} other {# items}}",
  "welcome": "Welcome back, {name}!",
  "notifications": "You have {count, plural, =0 {no notifications} one {# notification} other {# notifications}}",
  "gender": "{gender, select, male {He} female {She} other {They}} joined."
}
```

### Pluralization rules per locale

| Locale | Plural forms | Example |
|---|---|---|
| English | one, other | 1 item, 5 items |
| Arabic | one, two, few, many, other | 1, 2, 3-10, 11-99, 100+ |
| Chinese | other | 项目 |
| Russian | one, few, many, other | 1, 2-4, 5-21, 22+ |

**Rule:** Never concatenate strings. Always use ICU placeholders.

## Locale-Aware Formatting

```typescript
// Date
new Intl.DateTimeFormat('ar-SA', { dateStyle: 'full' }).format(date);
// Output: الأربعاء، ٢ يوليو ٢٠٢٦

// Number
new Intl.NumberFormat('de-DE').format(1234567.89);
// Output: 1.234.567,89

// Currency
new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'USD',
}).format(29.99);
// Output: $29.99

// Relative time
const rtf = new Intl.RelativeTimeFormat('ar', { numeric: 'auto' });
rtf.format(-1, 'day');
// Output: أمس
```

**Rule:** Use `Intl` built-ins — no moment.js, no date-fns locale imports. They're native, tree-shakeable, and cover all locales.

## Pseudo-Localization Testing

```bash
# Generate pseudo locale for testing
# en-pseudo.json — wraps every string in brackets, adds diacritics
{
  "nav.home": "[Ĥöṁé]",
  "dashboard.title": "[Ẏöüŕ Ḋäṡĥḅöäŕḋ]"
}
```

**What it catches:**
- Hardcoded strings (they won't have brackets)
- Text overflow in longer translated strings
- Missing ICU placeholders
- Concatenation instead of interpolation

Set `en-pseudo` as your default locale in dev mode. Toggle it on and verify every page.

## RTL (from 4j)

- `dir="rtl"` at document root, never per-element
- Logical CSS properties: `inset-inline-start`, `margin-inline-end`, `padding-inline`
- Tailwind: `ms-4` / `me-4` instead of `ml-4` / `mr-4`
- Flip directional icons with `scaleX(-1)`
- Test every page in both LTR and RTL
