# KNZiN Constitution

## Core Principles

### I. UI-Only Prototype
Every deliverable is static HTML + Tailwind + vanilla JS. No backend, no DB, no real payments. Dummy data inline.

### II. Mobile-First Single Page
375px first, 1280px desktop. Sticky header HUD, sticky bottom-nav mobile, sidebar desktop. RTL Arabic primary, EN toggle flips dir.

### III. Fidelity to Source
PDF + 17 images in Project info/ are truth. Pricing $2/part, $10/15-ticket bundle, 2000 IQD display. Countdowns, Hall of Fame, referral knzin.com/alifaraj, legal checkbox exact text.

### IV. Simplicity
Single index.html, Tailwind Play CDN, one js/app.js. No framework, no build step. Custom blue #1877F2, navy #0B1E3A, gold #F5B301. Font Tajawal.

### V. Observability
All interactive states visible: countdown ticking, marquee, modals, bottom-sheet, toasts. No dead buttons in prototype.

## Constraints
No real auth/pay/RNG/API. Mark all actions as demo with toast.
